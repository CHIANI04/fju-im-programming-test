## 檔名規則

* 格式：`分級+題號\_英文短名.py`，題號照刷題網站順序

  * 基礎題庫：`basic01\_hello.py`
  * APCS：`apcs2\_01\_xxx.py`、`apcs3\_01\_xxx.py`
  * 機測：`c01\_leopard.py`、`b07\_jolly\_jumper.py`、`a01\_xxx.py`
* 只用**英文小寫、數字、底線**，不要中文、空白、特殊符號（PC2 上傳規定）
* 一定存成 `.py`

\---

## 每題檔案格式

開頭資訊固定格式（冒號用全形「：」、分隔用全形「｜」），範例與筆記放最下面：

```python
# 題目：豹子
# 分級：機測 C級 #01
# 類型：N 型
# 關鍵字：骰子、三個一樣、Yes/No
# 技巧：split、len(set())
# 陷阱：無
# 狀態：第一輪 ✅（9/26）｜第二輪 ⬜

# ---- 程式 ----

# ===== 範例輸入 =====
#
# ===== 範例輸出 =====
#
# ===== 筆記 =====
# 1.
```

## 練習流程

1. 讀題 3 分鐘：判斷 N 型 / W 型，圈出輸出格式
2. 先自己寫：C 級卡 15 分鐘、B 級卡 25 分鐘，寫不出來再看解答
3. 執行程式，把範例輸入貼進終端機，輸出逐字比對（空格、標點、大小寫）
4. 上傳刷題網站確認綠燈
5. 隔天不看答案重寫一次
6. 更新索引卡、陷阱清單
