# A4 自我檢核表

會了就把 `[ ]` 改成 `[x]`。全部打勾大約就有解 B 級題的程度。

## 輸入與轉型
- [ ] `input()`（括號內不加任何提示字）
- [ ] `int()`、`float()`、`eval()`
- [ ] `input().split()`、`split(',')`、`split('|')`
- [ ] `map(int, input().split())`
- [ ] `.strip()` 去掉頭尾空白與換行

## 串列與字串
- [ ] 索引 `S[0]`、`S[-1]`
- [ ] 切片 `s[1:3]`、`s[::-1]`
- [ ] `len()`、`sum()`、`max()`、`min()`、`count()`
- [ ] `sorted()`、`sorted(lst, reverse=True)`、`set()`
- [ ] `",".join(lst)`、`" ".join(map(str, lst))`
- [ ] `append()`、`in`（判斷有沒有在串列裡）
- [ ] `isdigit()`、`isalpha()`、`upper()`、`lower()`

## 流程控制
- [ ] `for i in range(N)`（N 型）
- [ ] `while True` 加 `break`（W 型）
- [ ] `if`、`elif`、`else`
- [ ] 巢狀迴圈（兩層 `for`）

## 運算
- [ ] `%`（取餘數）、`//`（整除）、`**`（次方）
- [ ] 數字拆位：`n % 10`、`n // 10` 或 `for c in str(n)`
- [ ] 四捨五入寫 `int(x + 0.5)`，不要用 `round()`
- [ ] `ord()`、`chr()`（字母位移）
- [ ] 質數判斷：試除到 `int(n**0.5) + 1`
- [ ] `import math`：`math.floor()`、`math.ceil()`、`math.sqrt()`
- [ ] `int(s, 2)`、`bin(n)`（進制轉換）

## 輸出
- [ ] `print()` 在迴圈內直接輸出
- [ ] `f"{x:.2f}"`（小數位數）
- [ ] `f"{h:02d}"`（補零）
- [ ] `print(a, b)` 中間自動空一格；`print(a, end="")` 不換行
