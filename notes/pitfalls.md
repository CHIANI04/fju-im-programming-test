# 陷阱清單

PC2 是逐字比對輸出，下面這些都會讓邏輯正確的程式變紅燈。

## 一、上傳與考場
1. 檔名只用英文、數字、底線，不要中文、空白、特殊符號。
2. 一定存成 `.py`，不要存成 `.inpy` 或其他格式。
3. 送出時確認 Select Problem 選對題目、Select Language 選 Python。
4. 送出後等 10–30 秒結果，不要先按 OK；考試中不要按 Exit。
5. 考完先到講桌確認題數並**簽名**，簽完才能關機（沒簽名算零分）。

## 二、輸入
1. `input()` 括號內**不能**寫提示字，否則會被當成輸出。
2. `input()` 讀進來一定是字串，要算數字記得轉型。
3. 比對字串前先 `.strip()`，例如 `if line.strip() == "0":`（考場是 Windows，行尾可能多出看不見的字元）。
4. 一行只有一個值時要多次 `input()`，不要用 `split()` 硬拆。
5. 分隔符號不是空白時：逗號 `split(',')`、直線 `split('|')`。
6. 有前導零的號碼（例如 ISBN、`06`）要當字串讀，需要比大小時再轉 `int`。

## 三、計算
1. 四捨五入不要用 `round()`：Python 的 `round(2.5)` 是 2。正數寫 `int(x + 0.5)`。
2. 「捨棄小數」用 `int()`。
3. `/` 的結果一定是小數，要整數用 `//`。

## 四、輸出
1. 空格、標點、大小寫、換行都要和範例一模一樣。
2. 用 `",".join()` 接串列，避免最後多一個逗號。
3. 題目要求「每個後面都有空格」時（例如道路修復工），最後一個也要有。
4. 直接 `print(list)` 會印出 `[5, 5, 4]` 這種格式，只有題目範例長這樣才能用。
5. 題目敘述和範例不一致時，以**範例輸出**為準。
